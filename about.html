🌙 Project Purpose

This website was created as a dynamic collection showcase about zodiac signs. The project uses JavaScript arrays, objects, loops, filtering, conditionals, and modals to create an interactive experience.

☀ Features

✨ Filter zodiac signs by ruling planets

✨ Open a custom modal popup for hidden facts

✨ Dynamic cards generated with JavaScript

✨ Special glowing effects based on sign elements
